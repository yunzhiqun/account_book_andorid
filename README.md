# 记账本 Android 应用

一款简洁实用的个人记账应用，采用 Material Design 3 设计规范，支持账单管理、时间范围查询、数据备份还原等功能。

## 功能特性

### 核心功能

- **账单管理**：新增、编辑、删除账单记录
- **时间选择**：滚轮式时间选择器，精确到秒
- **分组显示**：按年/月分组，支持折叠展开
- **多选操作**：长按进入多选模式，批量删除
- **复制功能**：支持简要复制（金额等式）和全部复制（详情+等式）

### 查询功能

- **时间范围查询**：选择开始和结束时间，筛选账单记录
- **独立结果页**：查询结果独立显示，格式与主页一致
- **结果操作**：支持编辑、删除、复制筛选后的数据

### 备份功能

- **自动备份**：应用启动时检测，间隔 7 天自动备份
- **手动备份**：点击备份按钮随时备份
- **备份还原**：从本地备份文件恢复数据
- **备份管理**：查看、删除历史备份

## 技术栈

- **语言**：Kotlin 2.0.0
- **UI 框架**：Jetpack Compose + Material3
- **架构**：MVVM（Model-View-ViewModel）
- **依赖注入**：Hilt
- **数据库**：Room
- **异步处理**：Kotlin Coroutines + Flow
- **导航**：Compose Navigation
- **最低支持**：Android 8.0 (API 26)
- **目标版本**：Android 14 (API 34)

## 安装使用

### 从 Release 下载

1. 访问 [Releases](https://github.com/yunzhiqun/account_book_andorid/releases) 页面
2. 下载最新版本的 APK 文件
3. 在 Android 设备上安装（需允许未知来源安装）

### 从源码构建

1. 克隆仓库：
   ```bash
   git clone https://github.com/yunzhiqun/account_book_andorid.git
   ```

2. 使用 Android Studio 打开项目

3. 构建 APK：
   ```bash
   ./gradlew assembleRelease
   ```

4. APK 输出路径：
   ```
   app/build/outputs/apk/release/app-release.apk
   ```

## 使用说明

### 新增账单

1. 点击右下角悬浮按钮（+）
2. 输入金额（必填）
3. 添加备注（选填）
4. 选择时间（默认当前时间）
5. 点击"保存"

### 编辑账单

1. 点击账单记录
2. 修改内容
3. 点击"保存"

### 删除账单

**单条删除：**
1. 长按账单记录进入多选模式
2. 勾选要删除的记录
3. 点击删除按钮
4. 确认删除

**批量删除：**
1. 长按任意记录进入多选模式
2. 点击"全选"按钮
3. 点击删除按钮
4. 确认删除

### 查询账单

1. 点击顶部搜索图标
2. 选择开始时间和结束时间
3. 点击"查询"按钮
4. 查看筛选结果

### 备份数据

**自动备份：**
- 应用启动时自动检测
- 距离上次备份超过 7 天自动执行

**手动备份：**
1. 点击顶部备份图标（💾）
2. 等待备份完成

### 还原数据

1. 点击顶部还原图标（🔄）
2. 选择要还原的备份
3. 确认还原（将覆盖当前数据）

## 数据格式

### 备份文件格式

备份数据以 JSON 格式存储：

```json
{
  "version": 1,
  "timestamp": 1234567890,
  "recordCount": 100,
  "records": [
    {
      "id": 1,
      "amount": 100.0,
      "note": "午餐",
      "createdAt": 1234567890,
      "updatedAt": 1234567890
    }
  ]
}
```

### 复制文本格式

**简要复制：**
```
15+35.5+6+128=184.5
```

**全部复制：**
```
2024-01-01 12:00
午餐
100.00

2024-01-02 13:30
50.50

---
100.5+50.5=151
```

## 开发说明

### 构建要求

- Android Studio Hedgehog 或更高版本
- JDK 17
- Android SDK 34
- Gradle 8.5

### 代码规范

- 使用 Kotlin 官方代码风格
- 所有公共 API 添加 KDoc 注释
- 遵循 MVVM 架构模式
- 使用依赖注入管理对象创建

- 包含各种金额和备注类型

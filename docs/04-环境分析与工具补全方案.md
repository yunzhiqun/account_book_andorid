## 3. 工具补全方案

### 方案 A：安装 Android SDK Command-Line Tools（推荐，最轻量）

适合不需要 IDE、通过命令行构建项目的场景。

#### 步骤 1：下载 Command-Line Tools

```
下载地址：https://developer.android.com/studio#command-line-tools-only
选择：Windows 版本的 commandlinetools-win-xxxxxxx_latest.zip
```

#### 步骤 2：解压并放置

```
解压到：D:\environment\Android\Sdk\cmdline-tools\latest\
确保目录结构：
D:\environment\Android\Sdk\
├── cmdline-tools\
│   └── latest\
│       ├── bin\
│       │   ├── sdkmanager.bat
│       │   └── avdmanager.bat
│       └── lib\
```

#### 步骤 3：设置环境变量

```bash
# 系统环境变量中添加：
ANDROID_HOME = D:\environment\Android\Sdk

# PATH 中追加：
%ANDROID_HOME%\cmdline-tools\latest\bin
%ANDROID_HOME%\platform-tools
```

#### 步骤 4：使用 sdkmanager 安装必要组件

```bash
# 接受许可协议
sdkmanager --licenses

# 安装平台工具
sdkmanager "platform-tools"

# 安装 Android 14 平台 (API 34)
sdkmanager "platforms;android-34"

# 安装构建工具
sdkmanager "build-tools;34.0.0"

# 安装模拟器（可选）
sdkmanager "emulator"

# 安装系统镜像（可选，用于模拟器）
sdkmanager "system-images;android-34;google_apis;x86_64"
```

#### 步骤 5：验证安装

```bash
sdkmanager --list
# 应该能看到已安装的 packages 标记为 [x]
```

---

### 方案 B：重新安装 Android Studio（推荐，最完整）

适合需要可视化调试、布局预览、模拟器管理的场景。

#### 步骤 1：下载 Android Studio

```
下载地址：https://developer.android.com/studio
选择 Windows 版本安装包
```

#### 步骤 2：安装

```
安装路径建议：D:\environment\Android\AndroidStudio\
安装过程中选择自定义安装
SDK 路径设置为：D:\environment\Android\Sdk
```

#### 步骤 3：首次启动配置

```
启动 Android Studio → Setup Wizard
选择 Standard 安装类型
自动下载 SDK、Build Tools、Platform 等组件
```

#### 步骤 4：设置环境变量

```bash
ANDROID_HOME = D:\environment\Android\Sdk
```

## 4. 推荐方案

### 4.1 开发阶段推荐

| 场景 | 推荐方案 |
|------|----------|
| **当前（命令行构建）** | 方案 A：安装 Command-Line Tools + SDK |
| **后续调试** | 追加安装 Android Studio 或使用真机调试 |
| **模拟器测试** | 追加安装 Emulator + System Image |

### 4.2 最低安装清单

只需完成以下步骤即可开始编译本项目：

```
1. 下载 Command-Line Tools for Windows
2. 解压到 D:\environment\Android\Sdk\cmdline-tools\latest\
3. 设置 ANDROID_HOME 环境变量
4. 运行：sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
5. 运行：sdkmanager --licenses（全部接受）
```

安装完成后，项目中的 `local.properties` 文件需要配置：

```properties
sdk.dir=D:\\environment\\Android\\Sdk
```

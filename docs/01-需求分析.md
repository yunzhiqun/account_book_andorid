# 记账 App - 需求分析文档

## 1. 项目概述

一款简洁的 Android 个人记账应用，用户可以在消费后快速记录金额和备注，支持按时间查询、按年月折叠展示、批量删除、总计统计与复制等实用功能。

---

## 2. 功能需求

### 2.1 核心功能（P0 - 必须实现）

| 编号 | 功能 | 描述 |
|------|------|------|
| F-01 | 新增账单 | 点击"+"按钮，弹出输入界面；金额为必填，备注为选填；可仅输入金额即保存 |
| F-02 | 删除账单 | 单条记录左滑或长按删除 |
| F-03 | 修改账单 | 点击记录进入编辑界面，可修改金额和备注 |
| F-04 | 查询账单 | 按时间段查询，支持精确到年月日时分秒 |
| F-05 | 批量删除 | 勾选多条记录后一键删除 |
| F-06 | 年月折叠展示 | 默认按年→月→日三级折叠，展开当前月份数据 |
| F-07 | 总计显示 | 当前查询/展示区间底部显示总金额 |
| F-08 | 复制总计 | 将区间内消费以加法等式形式复制到剪贴板，如"1+2+2+4+2=11" |

### 2.2 查询功能详细规则

| 输入情况 | 默认值 |
|----------|--------|
| 只输入年 | 月=1，日=1，时=0，分=0，秒=0 |
| 输入年月 | 日=1，时=0，分=0，秒=0 |
| 输入年月日 | 时=0，分=0，秒=0 |
| 输入年月日时 | 分=0，秒=0 |
| 输入年月日时分 | 秒=0 |
| 输入年月日时分秒 | 使用用户输入值 |
| 不输入任何值 | 默认显示当前月份数据（当月1日 00:00:00 至 当月最后一天 23:59:59） |

### 2.3 展示规则

- 默认进入 App 时：显示当前月份数据
- 按年折叠：年份作为一级分组标题（如 "2026年"）
- 按月折叠：展开年后显示12个月份（如 "1月 (共XX条, ¥XXX.XX)"）
- 展开月后：显示该月所有记录，按日期倒序排列
- 底部总计栏：始终显示当前可见记录的总金额

### 2.4 复制功能格式

```
1.5+2+3.5+4+2=13
```

- 按时间顺序排列所有金额
- 使用 `+` 连接
- 末尾 `=` 后为总计金额
- 金额若为整数则不显示小数点，若有小数则保留实际小数位

## 3. 非功能需求

### 3.1 UI/UX 要求

| 编号 | 要求 | 描述 |
|------|------|------|
| NF-01 | 主色调 | 蓝白配色（主蓝 #2196F3，白底 #FFFFFF） |
| NF-02 | App图标 | DeepSeek 二创二次元女仆装鲸鱼娘 Q 版形象，抱着饭盆开心笑 |
| NF-03 | 界面风格 | 简洁美观，Material Design 风格 |
| NF-04 | 操作便捷 | 新增记录操作步骤尽量少（理想：打开→点+→输金额→保存，3步完成） |

### 3.2 数据要求

- 数据本地存储（SQLite / Room）
- 无需网络功能
- 数据持久化，App 关闭后数据不丢失
- 支持大量记录（至少 10,000 条无性能问题）

### 3.3 兼容性要求

- 最低支持 Android 8.0 (API 26)
- 目标版本 Android 14 (API 34) 或更高
- 适配不同屏幕尺寸（手机为主，平板兼容）

## 4. 用户故事

### US-01: 快速记账
> 作为一个用户，我在便利店消费了 15 元，打开 App 点击"+"，输入 15，可选填"便利店"，点保存，整个过程不超过 10 秒。

### US-02: 查看本月账单
> 作为一个用户，我打开 App 就能看到本月的所有消费记录，底部显示本月总计花了多少钱。

### US-03: 查询历史账单
> 作为一个用户，我想查看去年 3 月到 5 月的消费，点击搜索，输入起止时间，就能看到这段时间的所有记录。

### US-04: 复制账单给他人
> 作为一个用户，我选中这个月的所有记录，点击复制，得到"15+20+8.5+30=73.5"这样的格式，发给朋友或记账软件。

### US-05: 清理错误记录
> 作为一个用户，我发现有几条记录输错了，长按进入批量选择模式，勾选错误记录，一键删除。

## 5. 边界条件与异常处理

| 场景 | 处理方式 |
|------|----------|
| 金额为空 | 提示"请输入金额"，不允许保存 |
| 金额为 0 | 允许保存（可能是免费项目） |
| 金额为负数 | 不允许，提示"金额不能为负数" |
| 金额格式错误（如多个小数点） | 输入时限制，只允许数字和一个小数点 |
| 备注过长 | 限制 200 字以内 |
| 删除确认 | 单条删除弹出确认框，批量删除弹出确认框并显示将删除数量 |
| 无数据时 | 显示空状态插画（鲸鱼娘）和提示文字 |
| 查询无结果 | 显示"该时间段暂无记录" |

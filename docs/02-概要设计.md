# 记账 App - 概要设计文档

## 1. 技术选型

### 1.1 开发语言与框架

| 技术 | 选型 | 理由 |
|------|------|------|
| 语言 | **Kotlin** | 用户已安装 Kotlin 2.0.0，Android 官方推荐语言 |
| UI 框架 | **Jetpack Compose** | 现代声明式 UI，开发效率高，适合简洁界面 |
| 架构模式 | **MVVM** | Google 官方推荐，清晰分离 UI 与业务逻辑 |
| 数据库 | **Room** | SQLite 的 Kotlin 协程友好封装，类型安全 |
| 异步处理 | **Kotlin Coroutines + Flow** | 数据库查询响应式更新，UI 自动刷新 |
| 依赖注入 | **Hilt** | 简化 ViewModel、Room Database 等实例管理 |
| 导航 | **Navigation Compose** | Compose 原生导航支持 |

## 3. 数据架构

### 3.1 数据表设计

**表名：`account_records`**

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | 唯一标识 |
| amount | REAL | NOT NULL | 消费金额 |
| note | TEXT | DEFAULT '' | 备注（可选） |
| created_at | INTEGER | NOT NULL | 创建时间戳（毫秒） |
| updated_at | INTEGER | NOT NULL | 更新时间戳（毫秒） |

## 4. 核心流程

### 4.1 新增账单流程

```
用户点击 FAB "+"
       │
       ▼
弹出 AddEditDialog（金额输入框自动获焦）
       │
       ▼
用户输入金额（必填）+ 备注（选填）
       │
       ▼
点击"保存" ──► 校验金额 > 0 ──► 创建 AccountRecord
       │                              │
       │ 校验失败 ◄────────────────────┘
       │ 提示错误                      │
       │                              ▼
       │                     ViewModel.insert()
       │                              │
       │                              ▼
       │                     Repository → Room INSERT
       │                              │
       │                              ▼
       └────────────────────── Flow 自动刷新列表
```

### 4.2 查询流程

```
用户点击搜索图标
       │
       ▼
进入 SearchScreen
       │
       ▼
输入起止时间（部分字段可留空，自动补全默认值）
       │
       ▼
点击"查询"
       │
       ▼
ViewModel 处理时间补全逻辑：
  - 开始时间：未填的月日 → 当天，未填的时分秒 → 0
  - 结束时间：未填的月日 → 当天，未填的时分秒 → 23:59:59
       │
       ▼
Repository.queryByDateRange(start, end)
       │
       ▼
按年月分组，返回列表，更新总计
```

### 4.3 批量删除流程

```
用户长按某条记录
       │
       ▼
进入批量选择模式（顶部出现"取消/全选/删除"操作栏）
       │
       ▼
用户点击勾选多条记录
       │
       ▼
点击"删除"按钮
       │
       ▼
弹出确认对话框："确定删除选中的 N 条记录？"
       │
       ▼
确认 → ViewModel.deleteBatch(ids) → Repository → Room
       │
       ▼
退出选择模式，列表刷新
```

### 4.4 复制总计流程

```
用户在列表页点击"复制"按钮
       │
       ▼
ViewModel 获取当前展示区间的所有记录金额
       │
       ▼
AmountUtils.formatAsEquation(amounts, total)
  → 按时间顺序拼接："1.5+2+3.5+4+2=13"
       │
       ▼
CopyUtils.copyToClipboard(context, equation)
       │
       ▼
Toast 提示："已复制到剪贴板"
```

## 5. 页面结构

### 5.1 页面层次

```
MainActivity
    └── NavHost
         ├── HomeScreen（主页）
         │    ├── TopAppBar（标题 + 搜索图标）
         │    ├── LazyColumn（列表主体）
         │    │    ├── YearGroup（年折叠）
         │    │    │    └── MonthGroup（月折叠）
         │    │    │         └── RecordItem × N（记录条目）
         │    │    └── ...
         │    ├── TotalBar（底部总计 + 复制按钮）
         │    └── FloatingActionButton（+ 新增）
         │
         └── SearchScreen（搜索页）
              ├── TopAppBar（返回 + 标题）
              ├── 开始时间输入区（年/月/日/时/分/秒）
              ├── 结束时间输入区（年/月/日/时/分/秒）
              ├── 查询按钮
              └── 结果列表（复用 HomeScreen 的列表组件）
```
